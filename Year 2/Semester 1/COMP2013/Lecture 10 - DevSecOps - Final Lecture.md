Traditional security is a gateway check at a critical section - gatekeepers check if it is secure with a penetration testing team, checking if requirements have changed requests, code inspections, and more. 

In agile, there is usually a lead for security as part of the team. Every sprint in a scrum, this person ensures security is built-in. 

> Security practices should be built in to DevOps as opposed to at the end of the project. 

DevSecOps gives everyone the ability to contribute to security. Security is one of the highest indicators of code quality. If security tools are installed at the Dev level, all code written is secure code. Giving tools to developers earlier can reduce time spent to fix security issues by 50%.
