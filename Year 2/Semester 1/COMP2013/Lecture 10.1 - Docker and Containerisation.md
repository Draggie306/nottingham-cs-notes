
Microservices is the trend that industry is going: each service can call another service. Microservices are easier to manage, test and maintain as each process is decoupled.

Docker: allows dependencies and an app to be the same, packaged into a container. 

A container is run in the container runtime, alongside the host operating system, without OS configuration and runs one app at a time. 

A virtual machine runs on top of hypervisors, requiring emulation of hardware, requiring the configuration of the OS, but can run many apps at once. 

Traditionally:
“It works on my machine, why not in production”

Now:
“It works on all environment because it runs on Docker”
