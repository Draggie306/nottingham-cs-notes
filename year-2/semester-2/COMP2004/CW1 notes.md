

## Homepage

Sequence of Use principle
- Page designed to be hierarchical, from the top left to the bottom. 
- Top "At a Glance" section shows anomalies, warnings, and current status. For example, if an appliance is off but is usually on, it will be positioned there. Due to hands not reaching, it automatically cycles through all information without the user needing to swipe.

- The middle energy usage section shows the electricity and gas usage, and can be set to live use/daily/weekly/monthly, with a toggle for total cost over the period or the use of kWh. 

### Utility usage
- Sample data includes missing data, for example in the month view, it shows that it is not at the end of the month yet.


## Appliances

Designed around a metaphor: rooms. 
- Horizontal scrollable card carousels with images and text that do not appear fully, so it encourages the user to swipe to reveal it.
- Images can be customised and uploaded for each appliance. This is useful for all age ranges, as elderly people may find it easier to remember
